## Notes

- Crossref was useful for journal, DOI-bearing conference, and publisher-backed
  records, but exact-title API search sometimes returns neighbouring papers for
  older conference records. In those cases, the report uses DOI resolution,
  DBLP, official proceedings pages, arXiv, OpenReview, PMLR, ACL Anthology, CVF,
  or UCI pages as the authoritative checks.
- The bibliography intentionally avoids relying on unverifiable local files.
- The final manuscript embeds the bibliography directly in the LaTeX source, so
  the submission does not depend on a separate `.bib` or `.bbl` file.
